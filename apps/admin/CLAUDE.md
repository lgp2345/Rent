# 管理后台

基于 React + Vite 的房屋租赁管理后台，面向房东使用。

## 技术栈

### 核心框架

| 类别 | 选型          |
| ---- | ------------- |
| 框架 | React 19      |
| 构建 | Vite 8        |
| 语言 | TypeScript 5+ |

### 共享模块

| 类别 | 选型                                     |
| ---- | ---------------------------------------- |
| 验证 | `@repo/schema`（Zod schema，与后端共享） |

### 开发工具链

| 类别     | 选型     |
| -------- | -------- |
| 测试框架 | `vitest` |
| 代码质量 | `biome`  |

## 端口

| 服务             | 端口 |
| ---------------- | ---- |
| Admin 开发服务器 | 5173 |

## 测试策略

- 单元测试：组件 + hooks 逻辑
- 集成测试：页面关键流程
